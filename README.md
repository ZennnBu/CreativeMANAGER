
# WOWManager

An All-in-One Minecraft SMP Management Plugin.

## Features

- Server announcements
- Custom server spawn
- Spawn teleportation
- Custom player ranks
- Rank permissions
- Toggleable scoreboard
- Configuration support
- Paper API support

## Commands

| Command | Description |
|---|---|
| /announcement | Send announcement |
| /setspawn | Set server spawn |
| /spawn | Teleport to spawn |
| /rank create | Create rank |
| /rank delete | Delete rank |
| /rank set | Set player rank |
| /rank remove | Reset player rank |
| /rank list | List ranks |
| /scoreboard | Toggle scoreboard |
| /scoreboard reload | Reload scoreboard |

## Requirements

- Java 21
- Paper 1.21.11
